# Concept: fictional-media-lore

## 이름

창작물 설정 호기심 쇼츠

## 상태

초기 설정 완료. 현재 활성 concept.

## 목적

포켓몬·디지몬처럼 세계관과 팬덤이 있는 창작물의 설정, 캐릭터, 기술, 에피소드, 상품, 번역, 오해를 짧고 흥미로운 정보형 쇼츠로 소개한다.

## 이 concept을 사용할 때

- 공식 설정의 의외의 사실을 소개할 때
- 팬덤에서 자주 오해하는 내용을 풀 때
- 캐릭터나 기술의 배경을 설명할 때
- 에피소드 줄거리를 빠르게 요약할 때
- 상품·번역·수집 요소의 흥미로운 지점을 소개할 때

## 입력

매번 레퍼런스 영상을 다시 받지 않는다. 아래 입력만 받는다.

```text
주제: ...
반드시 포함할 정보: ...
피하고 싶은 방향: ...
```

## 출력

- 50~70초 세로형 쇼츠
- 주제에 따라 12~18개 장면
- 빠른 한국어 해설체
- 강한 제목 카드와 호기심 중심의 첫 문장
- 공식 정보·2차 자료·창작적 해석의 내부 구분
- 장면별 시각 자료 검색어, 자막, TTS 내레이션

## 연결된 자료

- 스타일: `references/shorts-style-profile.md`
- 파이프라인 설정: `config/pipeline.json`
- 대본 스킬: `skills/scriptwriter/SKILL.md`

## 레퍼런스 설정 상태

이 concept의 스타일은 사용자가 제공한 5개 쇼츠를 분석해 한 번 설정했다. 새 레퍼런스가 들어오면 기존 concept을 덮어쓰지 않고, 사용자가 갱신을 요청한 경우에만 스타일 프로필을 수정한다.
