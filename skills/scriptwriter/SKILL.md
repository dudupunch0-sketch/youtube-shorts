# Shorts Scriptwriter Skill

## 목적

사용자가 작성한 짧은 주제 노트를 약 60초짜리 쇼츠용 대본과 장면 목록으로 확장한다. 결과물은 이후 미디어 검색, TTS, 자막, 영상 합성 단계가 바로 사용할 수 있는 구조화된 JSON이어야 한다.

## 입력

```text
주제: ...
핵심 노트: ...
전달하고 싶은 느낌: ...
```

## 출력 규칙

1. 전체 내레이션 예상 길이는 55~65초를 목표로 한다.
2. 장면 수는 내용에 따라 결정한다. 기본 권장 범위는 12~18개다.
3. 각 장면은 하나의 핵심 내용만 전달한다.
4. 첫 장면은 시청자가 계속 볼 이유를 만드는 훅이어야 한다.
5. 중간 장면은 사실, 사례, 비교, 반전 중 하나를 사용한다.
6. 마지막 장면은 핵심 메시지를 기억하게 하는 결론이어야 한다.
7. 문장은 TTS가 자연스럽게 읽을 수 있도록 짧게 쓴다.
8. 각 장면에 `visual_query`, `visual_type`, `caption`을 함께 생성한다.
9. 사실처럼 말하는 내용은 확실한 정보와 추정/해석을 구분한다.
10. 특정 작가나 크리에이터의 문체를 그대로 모방하지 않는다.

## JSON 계약

```json
{
  "title": "영상 제목",
  "topic": "주제",
  "language": "ko-KR",
  "target_duration_sec": 60,
  "estimated_duration_sec": 60,
  "segments": [
    {
      "index": 1,
      "narration": "TTS가 읽을 문장",
      "visual_query": "검색 또는 이미지 생성용 설명",
      "visual_type": "photo|video|illustration|map|typography",
      "caption": "화면에 표시할 짧은 자막",
      "duration_sec": 4,
      "source": {
        "status": "pending",
        "source_url": null,
        "license": null,
        "creator": null
      }
    }
  ]
}
```
