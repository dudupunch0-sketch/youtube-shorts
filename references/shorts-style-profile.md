# Reference Shorts Style Profile

소속 concept: `fictional-media-lore`

이 문서는 제공된 5개 쇼츠에서 관찰한 공통 제작 규칙이다. 원본 영상의 문장, 장면, 이미지, 음성을 복제하기 위한 문서가 아니다. 새 콘텐츠를 만들 때 사용할 수 있는 형식과 리듬만 추출한다.

## 공통 형식

- 세로 9:16 영상. 확인한 파일은 360×640, 약 30fps였다.
- 시작 약 2초는 검은 배경 위의 큰 제목 카드로 시선을 잡는다.
- 제목은 2줄 안팎이며, 핵심 단어를 노란색으로 강조하고 나머지는 흰색으로 둔다.
- 본문은 애니메이션 장면, 공식 이미지, 상품 사진, 게임 화면, 도식, 밈성 컷을 빠르게 교체한다.
- 하단에는 내레이션 전체를 그대로 쓰기보다 핵심 구절을 짧은 자막으로 보여준다.
- 검정·흰색·노란색을 중심으로 사용해 자료 종류가 달라도 채널 인상이 유지된다.
- 영상마다 자료의 출처와 화풍은 달라도, 제목 카드와 자막의 고정 규칙이 일관성을 만든다.

## 말투와 리듬

### 기본 말투

- 친근한 한국어 해설체
- 짧고 단정적인 문장
- “그건 바로 …”, “의외로 …”, “때문에 …”, “결국 …” 같은 연결어를 활용
- 전문 용어를 먼저 던지고 바로 쉬운 말로 풀어준다
- 마지막은 가벼운 평가, 반전, 의외의 결론으로 닫는다

### 기본 전개

```text
의외의 주장 또는 질문
  → 정답을 빠르게 공개
  → 왜 그런지 설명
  → 공식 설정·장면·사례 제시
  → 오해/반전/수집욕/캐릭터성으로 마무리
```

줄거리형 콘텐츠는 다음 구조를 사용한다.

```text
상황 제시 → 사건 발생 → 문제가 커짐 → 숨은 사정 공개 → 결말
```

### 60초 확장 규칙

레퍼런스에는 20초대 영상도 많지만, 60초를 맞추기 위해 같은 문장을 늘이지 않는다. 하나의 주제를 다음 3~5개 정보 블록으로 확장한다.

1. 훅과 질문
2. 핵심 사실
3. 배경 또는 공식 설정
4. 구체적 사례·비교
5. 의외의 결론

각 블록은 2~4개 장면으로 나누고, 전체 장면 수는 대본의 호흡에 따라 12~18개를 기본값으로 삼는다.

## 콘텐츠 범위

초기 도메인은 포켓몬·디지몬처럼 **창작물의 설정, 캐릭터, 기술, 에피소드, 상품, 번역, 팬덤에서 생긴 오해**를 다루는 정보형 콘텐츠다.

주제가 확정되지 않았을 때도 이 형식을 유지할 수 있지만, 단순한 작품 소개보다 다음과 같은 질문형 소재를 우선한다.

- 왜 이런 설정이 생겼을까?
- 사람들이 무엇을 잘못 알고 있을까?
- 공식 설정과 팬들의 인식은 어떻게 다를까?
- 이 캐릭터·기술·상품의 의외의 배경은 무엇일까?
- 한 장면이나 이름에 숨은 정보는 무엇일까?

## 출처와 창작 허용 범위

정확성의 기준은 현실 역사·의학 콘텐츠처럼 절대적인 사실 검증을 요구하는 것이 아니라, **창작물 안에서 무엇이 공식이고 무엇이 해석인지 구분하는 것**이다.

모든 주요 주장은 다음 중 하나로 내부 표시한다.

- `official`: 공식 설정, 공식 사이트, 게임·애니메이션·도감·상품 정보
- `secondary_reference`: 나무위키, 팬 위키, 인터뷰 정리 등 2차 자료
- `creative_interpretation`: 여러 자료를 바탕으로 한 해석이나 재미를 위한 표현

`creative_interpretation`은 허용하지만, 공식 설정인 것처럼 단정하지 않는다. 출처가 충돌하면 대본에 짧게 불확실성을 표시하거나, 해석임을 밝힌다.

## 생성할 때 피할 것

- 레퍼런스 영상의 문장과 순서를 그대로 번역하거나 치환하기
- 출처가 없는 팬 이론을 공식 설정처럼 말하기
- 60초를 채우기 위해 같은 정보를 반복하기
- 모든 장면을 같은 이미지 형식으로 채우기
- 자막을 화면 전체 문장으로 가득 채우기
- 처음부터 복잡한 효과를 넣어 정보 전달을 방해하기
